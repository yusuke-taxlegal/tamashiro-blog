入れ方は4つ。迷ったら、上の2つ（公式のプラグイン）同じ道具に2つの方法で入れると、同じスキルが2つずつ並びます。1つの道具に1つの方法で

Claude Code のプラグインおすすめ

Claude Code を使っている方
claude plugin install mattpocock-skills@claude-plugins-official
  • コマンドは1行。更新も自動
  • grill-me を含む27個のスキルがまとめて入る

Codex のプラグインおすすめ

Codex を使っている方
codex plugin marketplace add mattpocock/skills codex plugin add mattpocock-skills@mattpocock
  • コマンドは2行。起動するたびに更新される
  • grill-me を含むスキルがまとめて入る

grill-me だけを入れる

ほかのスキルは要らない方
npx skills@latest add mattpocock/skills --skill grill-me --skill grilling -g
  • Node.js（22.20以上）が要る
  • 更新は自分でコマンドを打つ

日本語の grill-me を自分で作る

日本語で、1問ずつ聞いてほしい方
~/.claude/skills/grill-me/SKILL.md ~/.agents/skills/grill-me/SKILL.md
  • 説明書のファイルを1枚置くだけ
  • 作者の更新は届かない
