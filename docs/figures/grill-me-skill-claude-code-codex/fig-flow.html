grill-me は「作る前」に、AIから質問してもらういきなり頼むと、決めていなかったことに、できあがってから気づきます

いきなり頼む

やりたいこと「教室の月謝を管理するアプリを作って」
›
AIがすぐ作る決まっていないところは、AIが自分で想像して埋める
›
「そうじゃない」保護者もログインする前提になっていた、など
›
やり直し作った分だけ、直す手間も増える

grill-me を挟む

やりたいことまだぼんやりしていてよい
›
AIが質問する1問ずつ、または数問ずつ。どの質問にもAIのおすすめの答えが付く
答えるたびに、次の質問が変わる
›
決まったことを確かめる決まったこと・まだ決めていないことを並べる
›
ここから作る作業を頼むのは、自分が「これでいい」と言ってから
※ grill-me 自体は質問するだけで、ファイルを作ったり、作業を始めたりはしません。
