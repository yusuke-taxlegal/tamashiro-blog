P1本体のボタンと光の意味まず覚えるのは「✓ボタンを長押しで録音」だけで大丈夫です
電源ボタン（左の側面）長押しで電源を入れる・切る。入ると側面の小さなランプが白く光ります。
✓ HiDockボタン ＝ 録音3秒長押しで録音を始めます（止めるときも長押し）。録音中に軽く押すと、あとで見返す場所に印（ボイスマーク）が付きます。
通話ボタンイヤホンで通話しているとき、電話に出る・切る。
丸いつまみ（ボリュームノブ）回すと音量。押し続けている間だけ録音する「呟きモード」にもなります。
赤い丸 ＝ BNCボタン雑音を抑える機能のオン・オフ。録音のボタンではありません。
ミュートボタン自分のマイクを消す・戻す。消している間は赤く光ります。
BlueCatch（ブルーキャッチ）ボタン押すとBluetoothイヤホンとつなぐ。3秒長押しで切る。
光の色の意味
つまみの周りが水色（シアン）…録音中
白く点滅…印（ボイスマーク）を付けた
赤…マイクを消している
オレンジ…呟きモードで録音中
青（側面のランプ）…イヤホンとつながった
