# 記事一覧の間取り（トップ・読む）

- 合意した日：2026-10-17（玉城さん）
- 比べた試作：`design/ideas/2026-10-17-board-home.jpg`（トップ：いま／A案／B案）、`design/ideas/2026-10-17-board-blog.jpg`（読む：いま／C案／D案）
- 見た目（色・文字・余白）は今のまま。変えるのは並べ方と、一覧の1行の形だけ

## 決めたこと

1. 記事の一覧は、どこでも「1行型」にそろえる（いまの「最近よく読まれている記事」の形）
2. トップは **A案（区画を分ける）**
3. 読むは **D案（小さなジャンルボタン＋人気が先）**
4. ジャンルの名前は **3つにそろえる**（AIの使い方／仕事と暮らしの道具／経営と仕事の仕組み）。記事の frontmatter の `category` もこの3つに直す。本数の表示は全部消す
5. トップの一番上（写真と一言）は **小さくする**。一画面目から新しい記事が見えるようにする

## 1行型（一覧の1件）

```
┌──────┐ ジャンル名（12px・アクセント色）
│ 画像  │ 題名（15px・太字・3行で「…」）
│ 3:2   │ 2026.10.17（12px・灰）
└──────┘
  112px
```

- 画像は約112px・3:2。人気の一覧は左に順位の数字を足す（画像は少し小さく）
- 説明文・読む時間・「この記事を読む→」は出さない
- 1行全体を押せる。高さは約96〜110px（44px以上は必ず）
- 日付は人気の一覧にも出す（道具の記事は、いつ書いたかが判断材料になるため）

## 読む（D案）

```
┌──────────────────────────┐
│ 記事を読む                         │
│ 実際に試して、わかったこと。          │
│ (すべて)(AIの使い方)(仕事と暮らしの道具)(経営と…) │ ← 横に流せる小さなボタン1列
├──────────────────────────┤
│ よく読まれている記事                 │
│ 1〜3 の1行型                        │
├──────────────────────────┤
│ 新しい順                           │
│ 2026年10月                         │
│ 1行型 …（全部の記事を1ページに）       │
│ 2026年9月                          │
│ …                                 │
└──────────────────────────┘
```

- 本数（「全27本」「9本」）は出さない
- 記事が60本を超えたら「もっと見る」を考える

## あとから決めたこと（2026-10-17）

- ジャンルのボタンは、ジャンルごとのページへ移る（例：`/blog/ai/`）。見た目は「読む」と同じで、そのジャンルの記事だけが並ぶ。LINEで送れて、検索にも載る
- 記事ページの下の「ジャンル」のカード（`BlogGenreNav compact`）と「次に読む記事」も1行型にそろえ、本数は消す

## 別に直すこと

- 人気の一覧を集計する Worker（`ysk-life-engagement-sync`）が 2026-09-19 から公開し直されておらず、それ以降の記事が人気の一覧に出ない
