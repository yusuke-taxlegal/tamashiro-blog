部活から帰ってくるのは、だいたい19時前です。

汗をかいたまま玄関に入ってきて、ごはんを食べて、少し休む。そこから車で塾へ送り出すのは、正直なところ、本人にとっても親にとっても重い。

わが家の長男は中学2年生です。いま、**オンライン個別指導の「そら塾」**に通っています。通っている、と言っても家から出ません。自分の部屋で、決まった時間に画面をつなぐだけです。

先日、英語の点数が30点上がりました。

うれしかったので「なにが良かったの？」と聞いてみたら、思っていたより具体的な答えが返ってきました。この記事は、その息子の言葉を軸に、親の私が見ていたことを足したものです。

## 先に結論。「すぐ聞ける」が続くかどうかで決まる

そら塾に限らず、オンラインの塾が合うかどうかは、機能の数では決まらないと思っています。

決め手は、**子どもが「これ分からない」と口に出せるかどうか**です。

わが家の場合、そこがうまくいきました。息子いわく、いちばん大きかったのは先生1人に生徒2人という形式です。一斉授業ではないので、手を挙げるタイミングを待たなくていい。分からない場所で止まって、その場で聞いて、その場で解決できる。

逆に言えば、**自分から質問しない子には、この形式の良さが半分しか届きません。** そこは後半で正直に書きます。

まずは、そら塾がどういう塾なのかを整理します。

## そら塾はどういう塾か

| 項目 | 内容 |
| --- | --- |
| 運営 | 株式会社スプリックス（東証上場）。個別指導塾「森塾」などを運営 |
| 対象 | 小学生・中学生・高校生 |
| 形式 | オンライン専門の個別指導。先生1人に生徒2人 |
| 1コマ | 80分（小学生は60分の選択あり） |
| 受講機器 | パソコン・タブレット・スマートフォン。専用の機材は不要 |
| 講師 | 大学生の講師が中心。研修を受けたうえで指導にあたる |
| 教材 | 通っている学校の教科書に合わせたテキスト |
| エリア | オンラインのため全国。沖縄からも受講できます |

わが家が選んだ理由は、シンプルです。**部活のあとに、移動なしで受けられるから。**

沖縄は車社会なので、塾の送迎は親の時間をまるごと持っていきます。往復と待ち時間を足すと、毎回1時間以上。それが週に2回なら、月に8時間以上です。この8時間が消えるだけでも、家の中の余裕はだいぶ変わりました。

## 息子が話してくれた、そら塾の良かったところ

ここからは、息子本人の言葉をもとにしています。親が代弁すると美化してしまうので、なるべく本人の言い方を残しました。

### 1. 2対1なので、好きなときに質問できる

> この塾の魅力や良いところは、他の塾と違って一斉授業形式ではないので、好きな時に質問ができる点です。先生と生徒が2対1なので、先生と話せる時間が多く、本当に聞きたいこともすぐに質問できます。

「本当に聞きたいこと」という言い方が、私には引っかかりました。

一斉授業だと、みんなの前で聞ける質問と、聞けない質問があります。**「そもそもここが分かってない」という質問ほど、手を挙げにくい。** 中学2年ともなれば、なおさらです。

2対1なら、その質問が出せる。息子が言いたかったのは、たぶんそこだと思います。

### 2. 先生と話しやすい

> コミュニケーションが取りやすいのも魅力です。先生たちがとても優しく、大学生の先生が多いので非常に話しやすいです。そのため授業自体を楽しめますし、意思疎通もスムーズです。

大学生の講師が中心、という点は、見方によって評価が分かれるところです。

指導歴の長いベテランを期待する家庭には物足りないかもしれません。ただ、中学生にとっては**年齢が近いほうが質問のハードルが下がる**という現実もあります。

わが家は後者でした。「怒られそうだから聞かない」がないだけで、授業の中身が変わります。

### 3. 通塾時間がゼロになる

> 中学生だと部活から疲れて帰ってきた後、遠くの塾まで行くのは大変ですし、その移動時間が無駄だと感じる人もいると思います。家でパパッとすぐに授業を受けられるのは、大きなメリットです。

これは親の私も同じ意見です。

移動時間が減ると、削られるのは「移動そのもの」だけではありません。**帰宅してから塾に出るまでの、落ち着かない時間**も一緒になくなります。ごはんを急いで食べる、着替えを探す、送る親の予定を空けておく。この全部がなくなりました。

### 4. 自分のペースで進められる

> 普通の塾はみんな同じスピードで進みますが、ここでは自分のペースで学習できます。「今日はこれをやりたい」と言えば柔軟に対応してもらえるなど自由度が高く、自分が復習したい時に復習し、予習したい時に予習ができます。

「今日はこれをやりたい」が通る、というのは大きいと思います。

テスト前は範囲の復習に寄せる。授業についていけていない単元があれば、そこへ戻る。**自分の状態に合わせて内容を変えられるのは、個別指導の本来の価値**です。逆に言えば、集団塾でカリキュラムに引っ張ってもらいたい子には、この自由度が空回りする可能性もあります。

### 5. 英語が30点上がった

> 今回、英語の点数が30点も伸びました。その要因は、やはり2対1で先生に何でもすぐ質問できたことだと思います。分からないところをすぐに聞いて、その場ですぐに理解して解決できる。この「すぐ聞いて、すぐ答えが返ってくる」という質疑応答のしやすさが、成績アップに繋がったのだと感じています。

点数が上がった理由を本人が説明できる、というのが、私にはいちばんの収穫でした。

「なんとなく上がった」ではなく、「すぐ聞けたから上がった」。**再現できる理由を自分で持っている**なら、次のテストでも同じことをやればいい。

なお、これはあくまでわが家の一例です。成績の伸び方は本人の状況で変わりますし、この記事は成果を保証するものではありません。

## 親の私から見て、良かったこと

息子が挙げなかったところで、親として助かったことを3つ書きます。

**1つ目は、送迎がなくなったことです。** これは前述のとおりですが、効いているのは時間より「予定に縛られないこと」でした。仕事が長引いた日に、塾の時間を気にしなくていい。

**2つ目は、勉強している時間が見えることです。** 家で受けているので、授業の声が聞こえます。集中しているか、詰まっているかが、なんとなく分かる。塾に預けていると、この情報がまるごと消えます。

**3つ目は、費用が読みやすいことです。** 教室を持たない分、通塾型の個別指導塾より抑えられているのが一般的です。ただし、月謝だけを見ると判断を誤ります。これは後述します。

## 一方で、正直に書いておきたいこと

良いところだけを並べても、参考にならないと思います。検討する人が知っておいたほうがいいことを書きます。

### 授業の半分は、自分で解く時間になる

先生1人に生徒2人ということは、**先生はもう1人の生徒も見ている**ということです。

自分が問題を解いている間、先生はもう一方を見ています。この時間を「自分で考える時間」と捉えられる子には向いていますが、常に横についていてほしい子には物足りなく感じるはずです。

完全にマンツーマンを求めるなら、1対1のオンライン家庭教師など別の選択肢を検討したほうがいいと思います。

### 先生が固定されるとは限らない

同じ先生に長く見てもらう前提の仕組みではありません。相性の良い先生に当たったときの満足度は高い一方、担当が変わる可能性は織り込んでおいたほうがいいです。

### 通信環境と、集中できる場所が要る

当たり前ですが、家の回線が不安定だと授業になりません。

そしてもうひとつ、**家の中に「授業を受ける場所」を作れるか**が意外と大事です。リビングのテレビの音が入る場所では、80分は保ちません。わが家は自室の机に固定しました。

### 自分から質問できないと、良さが半分になる

繰り返しになりますが、ここが最大の分かれ目です。

そら塾の強みは「すぐ聞ける」ことです。聞かなければ、その強みは発動しません。おとなしい子の場合、**最初の数回だけ親が「今日は何を聞いた？」と確認する**くらいの伴走はあってもいいと思います。

質問の習慣さえつけば、あとは本人が回します。

## 向いていると思う子、慎重に考えたい子

| | こんな子には合いやすい | こんな子は慎重に |
| --- | --- | --- |
| 性格 | 分からないことを口に出せる | 何も言わずに固まってしまう |
| 生活 | 部活や習い事で夜が遅い | 家だと切り替えができない |
| 学習 | 苦手な単元に戻りたい | 決められた進度で引っ張ってほしい |
| 環境 | 自室など静かな場所がある | 家に落ち着ける場所がない |
| 目的 | 学校の授業と定期テストを固めたい | 難関校向けの特殊な対策が主目的 |

右の列に当てはまる場合でも、無理という意味ではありません。**先に手を打てば解決するものが多い**です。場所は作れますし、質問の習慣は練習でつきます。

## 無料体験で、確認しておきたい5つのこと

そら塾には無料体験があります。せっかくなので、「授業を受けてみた」で終わらせないほうがいいです。

わが家の経験から、体験のあとに子どもへ聞くとよいと思う質問を挙げます。

1. **今日、自分から質問できた？** ここがいちばん大事です。1回もできなかったなら、理由を聞きます。
2. **先生の話す速さは合ってた？** 早すぎても遅すぎても続きません。
3. **画面の文字は見えた？** スマートフォンだけで受けると、学年によってはつらい場面があります。タブレットやパソコンも試してください。
4. **80分、集中が保った？** 途中で切れたなら、時間帯や場所を変える余地があります。
5. **また受けたいと思った？** 最後はこれです。親が納得しても、通うのは本人です。

あわせて、親のほうで確認しておきたいのが次の3点です。

- 受講できる曜日と時間帯が、部活や家の予定と合うか
- 通信環境と受講機器を、どこに固定するか
- 振替や欠席の扱いがどうなっているか

塾を比べるとき、月謝だけを並べると必ず判断を誤ります。仕事で見積書を比べるときと同じです。

塾にかかるお金は、だいたい次の要素に分かれます。

| 項目 | 見るポイント |
| --- | --- |
| 月謝（授業料） | 学年と、週に何コマ受けるかで変わる |
| 入塾金 | 入るときの一度きり。免除の条件があることが多い |
| システム利用料 | オンライン塾では月額でかかることがある |
| 教材費 | 受ける科目の数だけ増える |
| 季節講習 | 夏期・冬期など。ここが一番ぶれます |

公開されている案内では、そら塾の中学1・2年は週1回で**月額7,800円〜**とされています。ただし学年・回数・時期で変わりますし、上の表のとおり月謝以外の費用もあります。**必ず公式サイトの料金ページと、申し込み時の案内で確認してください。**

私が家計として見るときは、**1年分の合計**を先に出します。月謝×12か月に、入塾金・システム利用料・教材費・季節講習を足す。この数字を出しておくと、途中で「思ったより高い」となりにくいです。

とはいえ、教室を持たないオンライン専門である分、通塾型の個別指導塾より抑えられているのは確かです。加えて、送迎のガソリン代と親の時間も計算に入れると、わが家の実感としては納得できる水準でした。

## よくある疑問

### スマートフォンだけで受けられますか

受けられます。ただし中学生の場合、**画面の大きさは体験のうちに確認したほうがいい**と思います。テキストと先生の画面を同時に見る場面があるので、タブレットやパソコンのほうが楽なことがあります。

### 沖縄からでも受けられますか

受けられます。オンライン専門なので、住んでいる場所は関係ありません。わが家も沖縄です。

### 先生1人に生徒2人だと、放置されませんか

放置というより、**交互に見てもらう形**です。自分が解いている間は先生がもう一方を見ています。その時間を自分で考える時間にできるかどうかで、感じ方が変わります。

### 部活で疲れている日でも続きますか

わが家の場合は、移動がないことが効きました。ただし「家に帰ってから受ける」ということは、切り替えが必要ということでもあります。時間帯は無理のない設定にしたほうがいいです。

### 本当に成績は上がりますか

上がる子もいれば、そうでない子もいます。わが家は英語が30点伸びましたが、これは一例です。**「すぐ聞ける形式を、本人が使いこなせたかどうか」**が分かれ目だと思っています。

### 親がやることはありますか

最初だけあります。通信環境と受講場所を整えること、そして最初の数回「今日は何を聞いた？」と確認することです。それ以降は、こちらから言うことはほとんどなくなりました。

## 最後に

塾選びは、教える内容そのものより、**続けられる形かどうか**で決まると思っています。

どんなに良い授業でも、部活のあとに車で40分かけて通う形が続かなければ意味がない。逆に、家で画面をつなぐだけなら、疲れている日でも受けられます。

わが家にとって、そら塾はその「続けられる形」でした。そして続いた結果として、息子が「すぐ聞けたから点が上がった」と自分の言葉で説明できるようになりました。

これから塾を探す方の、判断材料のひとつになればうれしいです。
