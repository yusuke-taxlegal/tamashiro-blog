# 2026-09-23 「いま読まれていること」をPCで横一列にする

## きっかけ
トップページの「いま読まれていること」が、PC表示だと記事が縦に3本積み重なり、
画面の左半分しか使えていなかった。スマホでは問題なし。

## 原因
`src/components/PopularArticles.astro` のCSSが、2つのランキング
（最近よく読まれている記事／読者の参考になった記事）を常に**左右2列**で並べる作りだった。
- 片方のランキングが条件（閲覧5件以上・参考3件以上など）を満たさず非表示になると、
  残った側が左半分に取り残される。
- 記事1本ずつは「サムネイル＋見出し」の横並びなので、狭い列の中で縦に積まれてしまう。

## 対応
画面幅900px以上のときだけ、レイアウトを次のように切り替えた（CSSのみ、HTML・JSは変更なし）。

- 2つのランキングは**上下に積む**（それぞれが幅いっぱいを使える）
- 記事3本は**横一列のカード**（画像を上、その下にカテゴリと見出し）
- 見出しは 0.92rem → 1rem に少し拡大

900px未満（タブレット・スマホ）は従来どおりで、表示は変わらない。

## 確認
- `npm run build` 成功
- `npx astro preview` をブラウザで目視確認：1440px / 1024px / 920px で横一列、
  760px / 375px は従来表示のまま崩れなし
  （ランキングAPIはCloudflare Pages Functions側のため、ローカルではダミーデータを流し込んで確認）
