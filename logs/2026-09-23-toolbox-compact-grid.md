# 2026-09-23 道具箱ページを「全品カタログ」に作り変える

## 依頼
- 道具箱を5品に限らず、画像をコンパクトにして数を載せられるようにする
- トップのコピーを変える
- 「仕事用2品を見る」「家庭用3品を見る」のボタンを削除する
- 見やすいデザインを一緒に考える

## やったこと（`feature/toolbox-compact-grid`）

### 1. 一覧（/toolbox/）に14品すべてを掲載
- 厳選5品だけを出す `selectedIds` を廃止し、仕事2品・家12品を全部並べる
- 数はデータから数えるようにしたので、道具を足すとタイトル・リード文・「○品」表示が自動で更新される

### 2. カードをコンパクトに
- 画像枠 270px固定 → `aspect-ratio:4/3`（1440pxで約227px）。1品あたりの高さは約760px → 約526pxへ
- 列数を増やした：PC 4列 / タブレット 3列 / スマホ **2列**（以前はスマホ1列）
- カード内は「分類 → 商品名 → 一言 → リンク → 広告表記 → ＋使い方と注意点（折りたたみ）」に整理
- 長い説明文（lead）と個別の注意書きは折りたたみの中へ移動。`＋ / －` の開閉マークを付けた

### 3. トップのコピーとボタン
- 見出し: 「まずは、この5品から。」→ 「使ってよかった道具を、ぜんぶ。」
- リード: 「使い方と注意点」の使い方を案内（当初は「仕事で2品、家で12品」と内訳を入れたが、
  今後増えていくため具体的な数字は置かない方針に変更。ページタイトル・説明文からも品数を外した）
- ヒーローの2つのボタンを削除（`.button-row` ごと撤去）

### 4. 詳細ページ（/toolbox/work/・/toolbox/home/）は読み物に
- `body.toolbox-detail` を付け、画像左・説明右の横並び1列に。説明文と注意点は最初から開いた状態
- 一覧＝見比べる、詳細＝じっくり読む、と役割を分けた

### 5. おすすめの印
- 玉城が特にすすめる6品（HiDock P1 / 日本通信SIM / SwitchBotロック / 食洗機 / ホットクック / 衣類乾燥機）に
  「おすすめ」バッジを付け、各セクションの先頭に並ぶよう並べ替え

## 守ったこと
- 購入リンクは `target="_blank" rel="sponsored noopener noreferrer"`、すぐ下に「広告・アフィリエイトリンクです。」
- ページ下部の広告表記（`disclosureNotice`）はそのまま
