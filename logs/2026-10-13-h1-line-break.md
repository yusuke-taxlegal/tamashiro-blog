# 2026-10-13 記事タイトル（H1）が言葉の途中で改行されないようにした

## なぜ
- 記事のタイトル（H1）は文字が大きく、1行に9〜10文字しか入らない。ブラウザは日本語をどの文字の間でも折り返すため、「録音時間を気にしな／い」「Gmailでメールの返／信が」のように言葉の途中で割れていた
- 画面幅によって割れる位置が変わるので、タイトルの言葉を選ぶだけでは直せない（全記事リライトの途中で分かった。`logs/2026-10-13-yasashii-bunsho-rewrite.md`）

## やったこと
- Google の BudouX（日本語を文節に分ける部品。`budoux@0.9.3`、Apache-2.0）を入れた。ビルドのときにタイトルを文節に分ける
  - CSS の `word-break: auto-phrase` は Chrome にしか効かず、iPhone の Safari では効かないので使わなかった
- `src/lib/phrases.ts`：タイトルを折り返してよいかたまりに分ける
  - BudouX の文節
  - 「組織と｜しての」と分かれるのは「組織としての」につなぎ直す
  - 製品名の空白（「CIO NovaPort SLIM」）でも折り返せるようにする
  - 1行に入らない長い文節は、英字と日本語の境目（「ChatGPT｜デスクトップ版の」「なぜ｜SeminarFlowを」）や、長いカタカナ語の単語の境目（「フラット｜スパイラル｜ケーブル」）でも分ける。1〜2文字だけ残る分け方はしない
- `src/layouts/BlogPost.astro`：かたまりごとに `<span class="title-phrase">`（inline-block）で包み、間に `<wbr>` を入れた。かたまりの中では折り返さない。1行に入らない長いかたまりだけ中で折り、そのときも「ー」や小さい「ッ」で行が始まらないようにした（`line-break: strict`）
- ほかのページの H1 は手で `<br>` を入れてあるので触っていない。ページの `<title>`・共有用の文字は変わらない

## 確かめたこと
- 全23記事 × 8つの画面幅（320・375・390・430・768・1024・1280・1440px）＝184通りで、H1 の改行位置を1文字ずつ測った
  - 文節の途中での改行：直す前143か所 → 0か所
  - 横へのはみ出し：0、1文字だけの行：0
- スマホ幅とパソコン幅の画面を撮って目で確かめた
- `npm run check`（型の検査）：エラー0（直す前と同じヒント1件のみ）
- `npm run build`：成功（33ページ）
- `npm audit`：入れる前も後も同じ11件。BudouX で増えたものはない
  - もとからある11件の中に Astro の重大な弱点（画像最適化まわり）がある。別作業で対応する
